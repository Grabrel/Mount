NERVI v1.0 — UPLOAD NO GITHUB
==============================

1. Extraia Nervi-v1.0-GitHub.zip no computador.
2. Abra a raiz do repositório Nervi no GitHub.
3. Envie os ARQUIVOS extraídos, não o ZIP principal fechado.
4. Mantenha todo o frontend na raiz. Não crie pasta assets/.
5. O arquivo SUPABASE_BACKEND_v1.0.zip deve permanecer compactado no GitHub.

Arquivos essenciais do site na raiz:
- index.html
- style-v100.css
- app-v100.js
- favicon.svg
- icon-nervi.svg
- logo-nervi.svg
- logo-nervi-dark.svg
- logo-nervi-compact.svg
- logo-nervi-compact-dark.svg
- .nojekyll
