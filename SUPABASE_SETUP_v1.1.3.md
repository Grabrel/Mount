# Nervi v1.1.3 — Supabase

## Nenhuma ação necessária nesta revisão

As alterações da v1.1.3 são de interface e usam as Edge Functions que já estão publicadas no projeto Nervi:

- `nervi-create-account`;
- `nervi-check-username`;
- `nervi-login`;
- `nervi-read-goal-link`.

Não execute novamente a migration da v1.1.2 apenas para instalar a v1.1.3.
Não é necessário cadastrar secrets nem publicar novas funções para estas alterações.

O arquivo `SUPABASE_BACKEND_v1.1.3.zip` é uma cópia de referência do backend compatível já utilizado na v1.1.2.
